# 🍕 Pizza Sales Analysis

## 📌 Overview

This project analyzes pizza sales data to understand sales performance, customer ordering trends, pizza category performance, pizza size preferences, and best- and low-performing pizzas.

The project uses **MySQL for data analysis and SQL queries** and **Power BI for data visualization and dashboard creation**.

---

## 🎯 Project Objectives

* Analyze overall pizza sales performance
* Calculate key business KPIs
* Analyze daily and hourly order trends
* Understand sales by pizza category
* Analyze sales by pizza size
* Identify top-selling pizzas
* Identify bottom-selling pizzas
* Build an interactive Power BI dashboard
* Present meaningful insights through data visualization

---

## 📊 Dataset

The dataset contains pizza sales transaction data with information such as:

* Order ID
* Order Date
* Order Time
* Pizza Name
* Pizza Category
* Pizza Size
* Quantity
* Total Price

## 🔄 Project Workflow

### 1. Data Preparation

The pizza sales dataset was prepared and loaded into MySQL for analysis.

### 2. SQL Analysis

SQL queries were created in MySQL Workbench to analyze sales performance and customer ordering patterns.

### 3. KPI Analysis

The following key performance indicators were calculated:

* **Total Revenue**
* **Average Order Value**
* **Total Pizzas Sold**
* **Total Orders**
* **Average Pizzas Per Order**

These KPIs are included in the project's SQL analysis.

### 4. Sales Trend Analysis

The project analyzes:

* Daily order trends
* Hourly order trends
* Percentage of sales by pizza category
* Percentage of sales by pizza size

### 5. Pizza Performance Analysis

The analysis also identifies:

* Total pizzas sold by pizza category
* Top 5 best-selling pizzas
* Bottom 5 best-selling pizzas

### 6. Power BI Dashboard

The SQL analysis was used to create an interactive **Pizza Sales Dashboard** in Power BI.

The dashboard presents important KPIs and charts to provide a clear overview of pizza sales performance.
